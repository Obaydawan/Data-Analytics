What XLOOKUP does
Searches a range and returns a matching value.
Better than VLOOKUP because it can look left and right.

Basic Syntax
=XLOOKUP(lookup_value, lookup_array, return_array)

Formulas I practiced today
=XLOOKUP(A2, Products!A:A, Products!B:B)
=XLOOKUP(A2, Products!A:A, Products!B:B, "Not Found")
=XLOOKUP(A2, Products!A:A, Products!B:B, "Not Found", 0)

XLOOKUP vs VLOOKUP
VLOOKUP  → can only look right, needs column number
XLOOKUP  → looks any direction, uses range directly
XLOOKUP  → handles missing values with 4th argument

When to use XLOOKUP
When matching IDs, names, or codes across two tables
Example: Match employee ID → return their salary
